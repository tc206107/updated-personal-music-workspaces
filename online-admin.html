连接 GitHub

粘贴一个 GitHub 细粒度令牌（PAT，只需本仓库 Contents 读写权限）。令牌只保存在你的浏览器 localStorage，不会上传到任何服务器。
创建方法：GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token → Repository access 选 Only select repositories 并勾选 updated-personal-music-workspaces → Permissions → Contents 选 Read and write。

已连接。编辑完成后点「保存并发布」。

联系方式（每行一条）

说明：保存并发布 会把 assets/data/works.json 与 assets/js/works.js 直接提交到 GitHub 的 main 分支， GitHub Pages 约 1 分钟内自动重新发布，公网立即生效；文件上传（音频/MIDI/源文件/封面）走同一通道。 建议先在本地 local-admin.html 或本页编辑确认，再保存发布。
